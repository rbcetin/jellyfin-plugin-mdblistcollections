MDBList Collections

From mdblist.com → Preferences → API Access.

Lists

One list per row: an mdblist.com list URL, user/slug or a list id. A collection name set here is applied on every sync; leave it empty to start with the list's own name and keep any rename you make in Jellyfin. The collection mirrors the list — items added to it by hand are removed on the next sync. Collections without a poster get a collage of the list's top items; an image you set yourself is kept.
Saving syncs right away. The scheduled task "Sync MDBList collections" also runs at startup and daily.
